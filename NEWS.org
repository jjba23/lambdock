All notable changes to this project will be documented in this file. Changes are listed per project release (tag) and within each tag there are details about changes, additions, fixes and removals.

This project adheres loosely to [[https://semver.org/spec/v2.0.0.html][Semantic Versioning]].

*[Unreleased]*

- Stacks: `(stack-item #:name "Downloads" #:path "~/Downloads" #:view-mode 'grid)`
  turns a dock icon into a folder popover, macOS Downloads style. The popover
  lists the folder (dot-files skipped, folders first, capped at 300 entries) in
  one of three view modes: an icon `grid`, a `list` of rows, or a `fan` of tilted
  cards painted by hand (GTK cannot rotate child widgets, so the fan snapshots
  rounded cards and hit-tests the clicks by rotating the pointer back into each
  card). The header shows the folder name, the item count and a button that opens
  the folder; the view mode can be switched from the context menu and is
  remembered per stack.
- The launchpad: `(launchpad-item)` adds an icon that opens a full screen
  layer-shell overlay with a search field and a grid of every installed
  application, parsed from the XDG desktop entries (locale-aware `Name`, `Exec`
  field codes stripped, `Hidden`/`NoDisplay` honoured, desktop ids deduplicated so
  Flatpak exports override the identical system entry). The list is rescanned on
  every open, `Escape` or a click on the backdrop closes it.
- Drag and drop: reorder icons by dragging them along the dock, drag one out of
  the dock to remove it, drop a `.desktop` file to add that application, or drop a
  folder to add it as a stack. Everything is stored in
  `$XDG_STATE_HOME/lambdock/layout-<settings>.scm` (order, removals, additions and
  per-stack view modes) and replayed on top of the settings file, so a generated
  configuration keeps working; `(dock-layout-reset! path)` forgets the overrides.
- Context menus: "Remove from Dock" on every pinned item, plus view-mode switching
  and "Open Folder" for stacks.
- New theme independent overlay stylesheet (`resources/css/overlays.css`) for
  stacks, the launchpad and the drag feedback, so they look right whatever dock
  theme is active.
- Add `dock-item-spacing` (default 4px) for the gap between dock items, plus
  `set-dock-item-spacing!` for live changes. The default reproduces the OS X
  dock's rhythm (icons about 0.3 x their size apart, counting the theme's button
  padding), and the README has a short section on spacing and sizing.
- Fix the REPL setters: `reload-dock!` was being defined in `(guile-user)`
  instead of `(lambdock core)`, so `(set-dock-theme! ...)`,
  `(set-dock-icon-size! ...)` and friends never redrew the dock.
- Tests: three new C suites (`desktop_entry`, `stack`, `dock_dnd`, 13 in total)
  and 30 new Scheme assertions (163 in total) for the new item types and the dock
  layout overrides. The C tests now run from the source root so they always
  exercise the modules in this tree.

*[Released]*

** v0.8.2 (2026-10-25)
- Fix the build against GTK < 4.18: the mirror transform no longer uses
  `gsk_transform_matrix_2d()`, which only recent GTK has
- Link libm explicitly instead of relying on another library pulling it in, so
  the binary and the tests link on stricter toolchains
- Packaging: the Arch PKGBUILD, the Debian changelog and the openSUSE spec now
  name 0.8.1/0.8.2 instead of 0.7.x (and the README's RPM examples no longer say
  0.1.0)
- Guix: the package wraps with GLib/GTK and depends on dconf,
  gsettings-desktop-schemas, shared-mime-info and hicolor-icon-theme, so the dock
  resolves the desktop's icon theme (and therefore app icons) instead of falling
  back to Adwaita

** v0.8.1 (2026-10-25)
- README: document the glass shelf properly -- every option with its default and
  clamped range, the geometry in one line, ten copy-pasteable recipes (flat,
  frosted plinth, subtle 3D, the OS X Mavericks platinum slab, dark smoked glass,
  overhanging icons with a long mirror, mirror-only, no glass at all, taskbar and
  side docks), what the extremes of each knob do, live tuning from the REPL, and
  how to restyle the material with the `shelf-*` CSS classes
- CI: move the Byggsteg pipeline to v2

** v0.8.0 (2026-10-25)
- One dock implementation described by plain numbers -- no modes, no presets:
  `dock-shelf-tilt`, `dock-shelf-perspective`, `dock-shelf-margin`,
  `dock-shelf-front`, `dock-reflection`, `dock-reflection-intensity` and
  `dock-reflection-blur`. All default to the classic flat capsule.
- `dock-shelf-margin` accepts negative values, which is how the OS X dock lets
  its icons overhang the shelf; `dock-shelf-front` is the glass (front face) in
  front of them.
- Icon reflections now fade over the front face, with a soft contact shadow
  under each icon and the white running-app glow dot near the outer edge
- New light frosted `css/shelf.css` modifier plus a rewritten `'macos-mavericks`
  theme (platinum slab, specular outer edge, bluish thickness band)
- Add `ui/shelf.c` (`LambdockShelfFrame` + `LambdockReflection`) with a unit
  test suite covering the derived geometry

** v0.7.5 (2026-10-22)
- Add a pure-Scheme unit test suite (~tests/scheme~) covering state, items,
  presets, loader and core
- Expand the C test suites (dock items, dock window, Guile bridge, popover menu,
  theme engine, icon resolver) with many more cases
- Fix an out-of-bounds read when scoping short CSS selectors
