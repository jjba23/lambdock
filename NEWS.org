*[Released]*

** v0.8.1 (2026-10-25)
- README: document the glass shelf properly -- every option with its default and
  clamped range, the geometry in one line, ten copy-pasteable recipes (flat,
  frosted plinth, subtle 3D, the OS X Mavericks platinum slab, dark smoked glass,
  overhanging icons with a long mirror, mirror-only, no glass at all, taskbar and
  side docks), what the extremes of each knob do, live tuning from the REPL, and
  how to restyle the material with the `shelf-*` CSS classes
- CI: move the Byggsteg pipeline to v2

** v0.8.0 (2026-10-25)
- One dock implementation described by plain numbers -- no modes, no presets:
  `dock-shelf-tilt`, `dock-shelf-perspective`, `dock-shelf-margin`,
  `dock-shelf-front`, `dock-reflection`, `dock-reflection-intensity` and
  `dock-reflection-blur`. All default to the classic flat capsule.
- `dock-shelf-margin` accepts negative values, which is how the OS X dock lets
  its icons overhang the shelf; `dock-shelf-front` is the glass (front face) in
  front of them.
- Icon reflections now fade over the front face, with a soft contact shadow
  under each icon and the white running-app glow dot near the outer edge
- New light frosted `css/shelf.css` modifier plus a rewritten `'macos-mavericks`
  theme (platinum slab, specular outer edge, bluish thickness band)
- Add `ui/shelf.c` (`LambdockShelfFrame` + `LambdockReflection`) with a unit
  test suite covering the derived geometry

** v0.7.5 (2026-10-22)
- Add a pure-Scheme unit test suite (~tests/scheme~) covering state, items,
  presets, loader and core
- Expand the C test suites (dock items, dock window, Guile bridge, popover menu,
  theme engine, icon resolver) with many more cases
- Fix an out-of-bounds read when scoping short CSS selectors

** v0.6.3 (2026-08-22)

- Improved APT packaging
