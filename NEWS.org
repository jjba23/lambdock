All notable changes to this project will be documented in this file. Changes are listed per project release (tag) and within each tag there are details about changes, additions, fixes and removals.

This project adheres loosely to [[https://semver.org/spec/v2.0.0.html][Semantic Versioning]].

*[Unreleased]*

- One dock implementation with a parameterised glass shelf: `dock-shelf-tilt`,
  `dock-shelf-perspective`, `dock-shelf-cover`, `dock-shelf-floor`,
  `dock-shelf-padding`, `dock-reflection`, `dock-reflection-intensity` and
  `dock-reflection-blur` (all defaulting to the classic flat capsule)
- `dock-special-mode` now selects a *preset* of those parameters; `'big-cat`
  gives the OS X Mavericks dock (14 degree projected shelf, 58% cover, glass
  floor, mirrored/blurred/fading icon reflections)
- Explicit shelf parameters override the preset, and every value is hot
  reloadable through the REPL
- Add the `'macos-mavericks` theme (the last 3D OS X dock)
- Add `ui/shelf.c` (`LambdockShelfFrame` + `LambdockReflection`) with a unit
  test suite; the shelf material ships as the scoped `css/shelf.css` modifier so
  any theme can wear it

*[Released]*

** v0.7.5 (2026-10-22)
- Add a pure-Scheme unit test suite (~tests/scheme~) covering state, items,
  presets, loader and core
- Expand the C test suites (dock items, dock window, Guile bridge, popover menu,
  theme engine, icon resolver) with many more cases
- Fix an out-of-bounds read when scoping short CSS selectors

** v0.6.3 (2026-08-22)
- Added Podman/Docker build and run
- Improved APT packaging
- Developed and improved RPM packaging


** v0.5.1 (2026-08-11)
- Fix REPL

** v0.5.0 (2026-08-11)
- Add dynamic apps and ~poll~ + ~poll_fn~
- Add re-usable dynamic apps and  widget presets for RAM, CPU, TEMP, etc
- Add multi-config support with hot-reload
- Add dock scrolling when overflow occurs
- Improve stability of the dock and animations are smoother
- Add hover animate toggle per item
- Improve CSS themes

** v0.4.1 (2026-08-07)
- Implement multi-monitor support and multi-instance
- Improve stability and fix crashes
